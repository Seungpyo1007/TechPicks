# Tokens

`techpicks.css` is the **application** brand contract. Its values come from
`lib/app/theme/tp_tokens.dart`, which samples the logo (`NBlogo_black.png`).

The web does not import this file. Its palette comes from the web design source
and lives in `site/styles/tokens.css`. See `docs/WEB_DESIGN_FIDELITY.md` for why
the two differ.
